# THE NUCLEUS &middot; top-p sampling

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **NIPHĒLEKTRON**.

THE NUCLEUS (top-p) &mdash; on THE ELECTRON's bench. You needn't let the electron wander the whole blizzard: nucleus sampling keeps only the smallest set of top words whose odds together reach p &mdash; the nucleus &mdash; and discards the long tail entirely, so it can be adventurous without ever landing on nonsense. Slide the cutoff on the three-corner layout; TAP THE STORM and the electron only ever lands inside the kept set (the tail never lights up). &#9670; LIT: the exact top-p algorithm (Holtzman et al., 2019) &mdash; sort, accumulate to p, renormalise, sample; the kept-set size, the cut tail and the true coverage recompute live. &#9650; AMBER: ten toy logits at fixed T=0.9 stand in for a real vocabulary; no model runs.
